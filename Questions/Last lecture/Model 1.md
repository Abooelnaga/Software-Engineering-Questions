# Software Engineering Review Questions

## Lecture 7: Software Documentation (20 Questions)

### 1. What is the primary purpose of software documentation?
a) To make the software more colorful.  
b) To keep track of all parts of a software project and aid understanding.  
c) To replace the need for developers.  
d) To increase the software's execution speed.

### 2. Without documentation, software is often compared to a:
a) White box.  
b) Black box.  
c) Transparent box.  
d) Toolbox.

### 3. A "black box" in software terms refers to:
a) A well-documented system.  
b) A system whose inner workings are hidden from the outside.  
c) A system with a user-friendly interface.  
d) A system that is fully tested.

### 4. Which of the following is a key guideline for effective documentation?
a) It should be open to multiple interpretations.  
b) It should be ambiguous to allow flexibility.  
c) It should be clear, precise, and unambiguous.  
d) It should be written only for the original developers.

### 5. Good documentation should be:
a) Lengthy and repetitive.  
b) Brief and free of repetition.  
c) Updated only at the end of the project.  
d) Written in a single language only.

### 6. Why is it important to keep documentation updated?
a) To increase the file size.  
b) To reflect recent changes and keep it relevant.  
c) To make it harder for new developers.  
d) To comply with legal requirements only.

### 7. Outdated documents should be:
a) Kept forever for historical records.  
b) Removed after finalizing all added content.  
c) Printed and archived physically.  
d) Translated into multiple languages.

### 8. How does documentation assist in project maintenance?
a) It makes maintenance more difficult by adding extra reading.  
b) It has no impact on maintenance.  
c) It makes maintenance easier by providing a reference.  
d) It automates the maintenance process.

### 9. Documentation helps new team members understand the software, which:
a) Increases training costs.  
b) Cuts down costs and efforts in training.  
c) Makes the software more complex.  
d) Is only useful for managers.

### 10. Which of the following is NOT a benefit of software documentation?
a) Tracking project parts.  
b) Improving software quality.  
c) Making the code run faster.  
d) Assisting in user training.

### 11. Knowledge sharing through documentation ensures:
a) Only the original developer understands the software.  
b) Knowledge is lost when someone leaves.  
c) Everyone can understand the software's work and usage.  
d) It increases security risks.

### 12. Which tool is mentioned as a trusted software documentation tool?
a) Microsoft Word  
b) GitHub  
c) Adobe Photoshop  
d) Windows Notepad

### 13. What is a characteristic of good documentation from the "Reader's View"?
a) It should be open to multiple interpretations.  
b) It should be understood clearly without ambiguity.  
c) It should be written in technical jargon only.  
d) It should be very long and detailed.

### 14. The guideline "Avoid repetition" means documentation should be:
a) Redundant to emphasize points.  
b) Brief and to the point.  
c) Repeated in multiple languages.  
d) Full of examples even if they repeat.

### 15. Documentation is particularly helpful during:
a) Software compilation.  
b) User training and onboarding.  
c) Hardware installation.  
d) Marketing campaigns.

### 16. What happens if documentation is not updated with changes?
a) It becomes more accurate.  
b) It remains useful forever.  
c) It becomes outdated and misleading.  
d) It automatically updates itself.

### 17. Which of these is a listed documentation tool?
a) Docz  
b) Visual Studio Code  
c) MySQL  
d) Apache

### 18. The process of documentation is described as:
a) A short, one-time task.  
b) A long procedure to keep the project on track.  
c) Unnecessary after development.  
d) Only needed for large projects.

### 19. After development, developers might find documentation unnecessary because:
a) They already know how everything works.  
b) The software is self-documenting.  
c) Documentation is automatically generated.  
d) They have memorized nothing.

### 20. Which of the following is a correct statement about software documentation?
a) It is only for external users.  
b) It is a living document that should evolve with the project.  
c) It is static and never changes after writing.
